Title:  I hate that we live in a world where I am going to keep this keyboard.

In my opinion this keyboard is obscenely overpriced, but is sadly the best split, low-profile, non-mechanical keyboard currently on the market.

It is very thin and compact.  The compactness is accomplished by putting some important keys like print screen behind an Fn key, and using 
using really small arrow keys (also pg up, pg down).  These features are a bummer, and I would prefer something closer to a standard tkl layout.

I would also prefer to have a slightly "sculpted" low profile key shape because it provides better positioning feedback than the chiclet profile used here.
However, I found that it's possible to adapt to the chiclet over time.

It should have a tenting attachment included, because it's really not "ergo" without that.

In this version they added a Bluetooth connection to the PC but still use a ugly, awkward, hardwired jumper cable to connect the left and right hand boards.  
The outer insulation of the jumper cable is not even glued to the grommet as it enters the keyboard housing, so a light tug reveals the inner conductors and shielding.
This was really poorly done -- even the open-source community has solutions for independently wireless boards.

A dim backlight would have been nice, understanding that this would reduce battery life. There is plenty of space for a bigger battery inside the casing (they used a single 230 mAh).

USB is a 6-pin power-only, so it has no data connection. So, no bluetooth, no keyboard input!
One of the consequences is that you can't enter bios or boot menu without attaching a separate keyboard.
The included usb cable is also power-only.

It's really a shame that they give no support for separately remapping the two halves of the spacebar key.  I asked customer support about this, but they brushed me off.

The macro column on the far left side of the board, which triggers key combinations internally, was a strange choice.
Luckily they are mapped to Roya-[z,a,x,v,c] rather than ctrl-[z,a,x,v,c], so they can be remapped in software.
The upper-right-most key being used to disable this macro column is a waste of a key in my opinion.

The keyboard has a RGB LED which is supposed to remind you to take breaks.  But you need to install software to use it, which monitors your keyboard and mouse usage and I see no reason to trust it.
The led also flickers very noticably, which is annoying.

Overall, I think r-go should to redesign this board to justify its price tag.
